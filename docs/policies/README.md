## Positioning Strategy

These policies are built around one core trust angle: **buying direct from Kawai is the safest, most protected way to buy a Kawai piano.** The manufacturer is the highest-trust seller — not a dealer, not a marketplace.

Key messages embedded across all policies:
- Factory warranty only valid on authorized/direct sales (protects against gray market)
- Free return freight on all tiers — customer never pays for a return
- White-glove delivery standard on all acoustic instruments, not an upsell
- Price match against any authorized competitor removes "let me check around" friction
- 0% financing surfaces affordability at the product level, not just at checkout
