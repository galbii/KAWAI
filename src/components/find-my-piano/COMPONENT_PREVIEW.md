## Animation Flow

### On Scroll (IntersectionObserver triggered at 20% visible)

**PianoTypeComparison:**
1. Section header fades + slides up (0.7s)
2. Table rows stagger in from left (0.5s each, 0.1s delay between)
3. Mobile cards stagger in from bottom (0.6s each, 0.1s delay between)
4. Bottom CTA fades + slides up (0.6s, 0.6s delay)

**UseCaseCards:**
1. Section header fades + slides up (0.7s)
2. Cards stagger in from bottom (0.6s each):
   - Card 1: 0.2s delay
   - Card 2: 0.3s delay
   - Card 3: 0.4s delay
   - Card 4: 0.5s delay
3. Bottom CTA fades + slides up (0.6s, 0.8s delay)

### Hover Effects

**PianoTypeComparison Table:**
- Row hover: `bg-white/50` transition 200ms
- Link hover: `kawai-red → kawai-black` transition 200ms
- Model chips: No hover (desktop), tap highlight (mobile)

**UseCaseCards:**
- Card hover: `shadow-sm → shadow-lg` + icon scale 110%
- Model chips hover: `bg-kawai-red/10 → bg-kawai-red` + `text-kawai-red → text-white`
- CTA arrow: `translate-x-0 → translate-x-1`

├─ text-kawai-red (#e21d30)        - Accents, links, icons, labels

├─ text-kawai-black/80             - Secondary text (80% opacity)
├─ text-kawai-black/70             - Tertiary text (70% opacity)

├─ border-kawai-pearl              - Card borders
├─ border-kawai-pearl/50           - Subtle borders (50% opacity)

## Responsive Breakpoints

```
Mobile (default):     320px - 639px   → Stacked cards
Tablet (sm):          640px - 767px   → Stacked cards, larger text
Tablet (md):          768px - 1023px  → 2x2 grid starts (use cases)
Desktop (lg):         1024px - 1279px → Table view (comparison), 2x2 grid
Large Desktop (xl):   1280px+         → Full table view, optimal spacing
```

## Accessibility Features

**Keyboard Navigation:**
- All links and buttons are focusable
- Focus states with visible outlines
- Tab order follows visual flow

**Touch Targets:**
- Minimum 44px height for all interactive elements
- Cards have ample padding for easy tapping
- Chips/tags are 36px+ in height

**Screen Readers:**
- Semantic HTML structure
- Descriptive link text (no "Click here")
- Proper heading hierarchy (h2 → h3 → h4)
- ARIA labels where needed

**Color Contrast:**
- All text meets WCAG AA standards
- Red (#e21d30) on white: 5.2:1 ratio (AA Large)
- Black (#1a1a1a) on white: 16.8:1 ratio (AAA)
- White on black: 16.8:1 ratio (AAA)

## File Sizes & Performance

**Component Bundle Sizes (estimated):**
- PianoTypeComparison.tsx: ~12 KB (minified)
- UseCaseCards.tsx: ~10 KB (minified)
- Combined with Framer Motion: ~45 KB total

**Image Assets Needed:**
None! All icons are inline SVG (optimized for performance)

**Loading Strategy:**
- Components are lazy-loaded via IntersectionObserver
- No render until scrolled into view (saves initial page load)
- Animations only fire once per session

**Core Web Vitals Impact:**
- LCP: No impact (no images, text only)
- CLS: Zero layout shift (fixed heights, no dynamic content)
- INP: <50ms (smooth animations, no heavy JS)
